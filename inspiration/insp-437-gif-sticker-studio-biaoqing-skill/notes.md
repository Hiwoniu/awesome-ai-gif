# 笔记

## 它是怎么做的

这套 Skill 不内置生图模型，先用外部工具做出连续动作帧或视频，再交给它整理。流程是导入素材、逐帧预览确认动作、叠加可自选中文字体的字幕层、按单张 500KB 的默认目标压缩，最后分批打包并做交付校验。制作前有环境检查脚本，交付前有验收脚本逐个核验 GIF 的正方形、循环、大小、帧数与时长。本机需要 Python 3.10 以上，导入视频时另需 FFmpeg。

## 我们怎么用

我们用原创角色重做时，只借它的后半段流程：动作帧先逐帧检查、字幕单独分层、压缩打包前逐项校验。角色、动作和文案全部换成我们自己的原创内容，不直接使用仓库里的示例素材。
