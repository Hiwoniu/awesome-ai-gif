# 笔记

## 它是怎么做的

文章从开发者视角拆解 Images 2.6 的 GIF 能力：两个模型档位按速度与质量分工（快的档位出图快、精的档位质量高），API 输出 GIF 的做法按步骤讲清，帧数与单帧时长按表情包、产品旋转等场景各给参考区间，还提了一条精灵图转动画的路线，并提醒 GIF 256 色、无半透明这类硬限制。

## 我们怎么用

借它按场景给帧数/时长搭配的经验规则和选型口诀，做我们自己的规格表时对照；API 路线适合以后批量出图时参考。硬限制提醒（256 色、无半透明）要在设计阶段就考虑进去，避免出图后再返工。
