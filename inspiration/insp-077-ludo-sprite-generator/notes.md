# 笔记

## 它是怎么做的

- 入口是文字描述或上传角色，产出动画精灵表；动作有四种驱动方式：直接写动作提示词、最多放 3 个关键帧、从参考视频迁移动作、从 641 个动作预设里挑。
- 成环靠关键帧首尾同姿势：第一个与最后一个关键帧用同一姿势，循环播回起点时不跳帧。
- 同一动作可以换 8 个朝向复用：角色控制器思路，一套动作、八个方向，适合游戏角色与多角度表情。
- 交付是透明 PNG 精灵表加 TexturePacker JSON，帧位置与尺寸都写进 JSON，游戏引擎或网页可以直接读。
- 免费样张标注了帧数与尺寸，动作预设按类别组织，挑动作时先看分类、再看具体动作。

## 我们怎么用

- 借四种动作驱动的分类：我们的精灵表也可以按提示词、关键帧、视频迁移、预设库四档来规划动作来源，而不是每次都从头写提示词。
- 借首尾同姿势的成环做法：做循环先定首尾同一姿势，再补中间帧。
- 借透明 PNG 加 JSON 的交付格式：精灵表配一份帧位置 JSON，比只给一张图更方便复用。
- 借 8 方向复用的思路：同一动作换朝向就能扩出一组，适合做成套的游戏风表情。
