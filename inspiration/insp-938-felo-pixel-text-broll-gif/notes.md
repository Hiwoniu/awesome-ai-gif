# 笔记

## 它是怎么做的

Felo 上的这个 GPT Image 2.6 案例是一张像素风文字动效 GIF：深青色底上，奶油色像素字体的 B-ROLL 逐个字母从左到右跳起再落回原位，下方一条珊瑚色光标条随之滑动，拼写与间距全程不变，短而平滑地无缝循环。案例页给出了提示词的结构：先定字体与配色、再定逐字跳动的动作、再定光标条的滑动、最后用一致性约束锁住拼写间距，并要求短平滑的无缝循环。原始出处是 ailingqu 的 GitHub 仓库 Awesome AI GIF Prompts，授权 CC BY 4.0。

## 我们怎么用

借“逐字跳动+滑动光标条”的双层文字动效结构：做文字类动态海报或 B-roll 贴片时，用一个主动作（逐字跳动）加一个次动作（光标滑动），并加拼写间距不变的约束。换我们自己的文字内容与配色，不照搬 B-ROLL 这个词与它的提示词原文。
