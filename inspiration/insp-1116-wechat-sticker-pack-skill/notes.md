# 笔记

## 它是怎么做的

这个 Skill 的顺序很讲究：先锁定角色基准（长什么样、什么画风），再做主题策划，然后编排提示词，最后按微信表情开放平台的规格自动校验素材——尺寸、格式、体积、透明度、GIF 循环设置，输出校验报告或 JSON。成套表情保持角色一致，场景之间是自然差异化，不是简单换文字、换表情。MIT 开源。

## 我们怎么用

借它的工作流顺序和校验脚本思路：我们自己的 Skill 也可以按“锁角色 → 策划主题 → 编排提示词 → 规格校验”四步走，校验清单直接对照微信官方规格做一份。它“参考主流表情包的功能与节奏，不复刻具体作品”的原则表述也值得借到我们的规则里。只借流程与校验思路，不抄它的代码和提示词原文。
