# 笔记

## 它是怎么做的

全程三步：测卡片 LPI、放卡、进 Studio 打印。LPI 是每英寸透镜线数，Studio 按它把图切条交错；0.1 的误差就会出条纹、翻面不干净，xTool 卡一般约 75.1，批次不同要实测。Studio 光栅编辑器分场景：换图 2-5 张、倾斜切换；可打印动画 5-12 帧连续帧，像翻页一样播；3D 效果 8-20 张同一物体不同角度，角度变化控制在 45° 内；自由创作 2-20 张。透镜纹路须与机器 X 轴平行，否则重影。

## 我们怎么用

借“按效果分档定帧数”的思路：我们的光栅卡案例可以先定效果（换图/动画/3D）再定帧数档；LPI 实测的校准意识也可以写进验收清单。
