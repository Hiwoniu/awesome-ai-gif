# 笔记

## 它是怎么做的

SkillHub 社区 Skill「微信表情制作」（wx-sticker-kit v1.0.0）：把微信表情合辑的上架素材规格写进 Skill——表情图/封面/图标默认透明，横幅与赞赏图必须彩色不透明且铺满画布，每表情含义词≤4 字；附 skillhub install 安装流程与各客户端 skills 目录。

## 我们怎么用

把这套素材规格表直接作为表情包类验收清单：透明/不透明、横幅铺满、含义词≤4 字；以后写我们自己的表情包 Skill 时也照“把平台规格写进 Skill”的方式组织。
