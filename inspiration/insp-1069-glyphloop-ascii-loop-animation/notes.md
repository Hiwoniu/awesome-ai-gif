# 笔记

## 它是怎么做的

工具形态：浏览器工作室、CLI、MCP 三种入口；动画类型有流场、波干涉、变形噪声团、矩阵雨、旋转 3D 形体；可导入图片或视频并继承其色彩；导出 PNG/GIF/MP4、网页嵌件、终端播放器；Agent 可通过 MCP 用表达式字符串自定义动画。无缝循环靠数学保证：噪声沿二维圆采样，正弦相位以 2π 整数倍推进，第 N 帧精确接回第 0 帧。

## 我们怎么用

给动态海报/签名档试一条“代码生成动效”路线：用字符画风格做背景动效，主体仍用自家原创角色；数学循环原理可迁移到任何逐帧生成流程的接缝验收。
