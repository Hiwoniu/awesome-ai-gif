# 笔记

## 它是怎么做的

多工具串联的动态字体案例：手绘字母 → Illustrator 描摹 → Flora 导入 → GPT Image + Nano Banana Pro 结合字母造型与花丛照片生成植物字母 → 四角度空房间 + 字母轮廓定形防走样 → Seedance 2.5 做 360 度环绕藤蔓生长镜头 → 按音乐节拍剪辑成片。

## 我们怎么用

借这条链路的两个关键点：一是“字母造型 + 参考图双图投喂”，二是“四角度空房间定形”防走样。动态海报里做标题字动效时，可以先定字母造型、再套植物或材质，最后用视频模型做环绕运镜。原帖未打开核实，链路细节以原帖为准。
