# 笔记

## 它是怎么做的

一个套壳 GPT Image 2.6 API 的单页生成器，入口只有两种：输一句话，或传一张照片加一句话。模型固定用 Flare，输出固定 512×512、8 帧无限循环；速度分慢/中/快三档，对应每圈约 2 秒、1.2 秒、0.7 秒；可勾选透明背景。页面附了 11 月 5 日六次实测数据：每次 12～19 秒、2 个点数，新账号 5 点数可做 2 张。提示词建议只写一个小动作（挥手、眨眼、小跳、蒸汽上升），文字放引号里且保持简短，背景用纯色或透明。页面下方的灵感来自 X 上线首日玩家的做法。

## 我们怎么用

借它“把参数钉死”的产品思路：做贴纸类 GIF 时先定死规格再写提示词——512 方形、8 帧、三档速度按动作快慢选；动作只写一个，文案用引号短词；透明背景只在需要抠图贴纸时开。角色与文案换我们自己的原创角色，不搬页面示例。
