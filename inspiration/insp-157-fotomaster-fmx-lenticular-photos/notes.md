# 笔记

## 它是怎么做的

工作流是拍照或 AI 照片来源 → 转光栅 → 预览（可选）→ 打印份数。两张照片做换图要正好两张源图，三张要正好三张，来源不能重复；卡片方向由第一张源图决定，横图出横卡、竖图出竖卡。预览步骤可设光栅预览，直接播原始帧动画，不显示条纹打印栅格。打印用本地 Windows 驱动或 DNP 热文件夹路线，FMPrint 不支持光栅打印。透镜片按 40、50、60、75 或 100 LPI 选。

## 我们怎么用

借“预览播帧动画”的做法：光栅卡案例验收时先看帧动画顺不顺，再看条纹交错；两到三张源图的约束可以写进双图翻转卡的取材要求。
