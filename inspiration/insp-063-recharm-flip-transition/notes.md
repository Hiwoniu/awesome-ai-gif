# 笔记

## 它是怎么做的

- 转场 0.8 秒、24 帧：A 片段的最后 0.8 秒与 B 片段的开头 0.8 秒重叠，逐帧翻过去。
- 每一帧的翻转角度用三次缓动算，再把画面当卡片绕竖轴转：角落按透视投影重算位置，相机距离固定；翻到 90 度之前显示 A，之后显示印在背面的 B。
- 细节：卡片翻到侧面时会变暗（边缘变暗约 45%），翻的过程中还会往后退一点，营造纵深；卡片外的区域填深色。
- 教程给了实测过的提示词与完整 Python 脚本，Claude 跑完脚本再拼接，两种用法都验证过。

## 我们怎么用

- 借它的翻面帧参数：做光栅变画卡或翻面海报时，0.8 秒、24 帧、三次缓动可以直接当分镜与帧参数的起点。
- 边缘变暗与往后退这两个细节值得学：翻面不是单纯旋转，加了变暗与纵深才像真卡片。
- 换掉对方的示例片段，只借翻面数学与帧参数；脚本本身不直接搬。
