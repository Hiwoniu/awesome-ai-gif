# 笔记

## 它是怎么做的

ChatGPT 一次生成 3×2 六格精灵表，同一角色、同一光线背景，只有右臂六个姿势变化（下→起→上→左摆→右摆→回落），第六帧接回第一帧。Claude Code 写脚本找白缝切图（不用等分切，因为格子宽度不完全一致），按不动部位（左半边把手、脸、脚）对齐裁切，再用 ffmpeg palettegen/paletteuse 合成 6fps 循环 GIF；同时出一张六帧横条 sprite.png，网页用 CSS steps(6) 播放。邮件里只用 GIF，因为多数邮件客户端不支持 CSS 动画；Outlook 桌面版可能只显首帧，所以首帧必须本身就是一张完整好看的静图。

## 我们怎么用

借这条精灵表路线做吉祥物挥手/点头类循环：角色换成我们自己的原创角色，六帧只动一个部位，第六帧回落到第一帧姿势；切图时按不动部位对齐防抖；交付时 GIF 与 CSS sprite 双份，邮件场景只发 GIF 且首帧当封面验收。
