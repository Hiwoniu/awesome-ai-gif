# 笔记

## 它是怎么做的

角色简介或参考图进来后，先定一个方向锚点（示例里是一张朝西的“Clockwork Courier”），身份记录列出帽子、护目镜、外套、挎包等辨认要素。动作逐个生成，脸漂移、躯干旋转这类失败尝试会标 Rejected 留在记录里，只有通过的 8 帧走路循环被打包成透明精灵表，附运行元数据。免费 500 点，不用绑卡；另有 API 与 Skill，coding agent 可以建任务、查进度、下载成品。

## 我们怎么用

借“锚点审一次、被拒留痕”的纪律：我们自己的精灵表案例也可以先定锚点再扩动作，失败帧留档不直接删，方便回看哪一步走样。API/Skill 的任务形态值得参考。
