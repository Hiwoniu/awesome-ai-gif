# 笔记

## 它是怎么做的

- 用 Sunburst 模型实测 8 个电商 GIF 案例，每个案例都给了尺寸、帧数、帧时长与文件大小：商品 360 度旋转、跑鞋弹跳、口红色号切换、促销角标脉冲、吉祥物挥手、咖啡蒸汽、Logo 逐笔绘制、文字逐字出现。
- 提示词结构是主体加单一运动轨迹加固定机位加循环指令：一个主体、一条运动轨迹、机位不动、末尾要求循环。
- 参数按场景搭配：尺寸按 512 或 768 选，帧数 2 至 16 帧，帧时长 100 至 500 毫秒；动作幅度大的多给帧、每帧短，幅度小的少给帧、每帧长。
- 成本按拼图网格档位计：同档内帧数不同价格一样，选帧数时先看档位、再看动作需要多少帧。
- 透明底有限制：不是所有场景都能要透明底，电商主图多半还是不透明底更稳。

## 我们怎么用

- 借按场景选参数的搭配表：做动态海报先定场景（旋转、弹跳、脉冲、蒸汽、逐字），再查尺寸、帧数、帧时长。
- 借主体加单一运动轨迹的结构：海报动效一次只动一条轨迹，不要多动作叠加。
- 借按网格档位计费的判断：出图前先算档位，避免为多一两帧多花一份钱。
- 借三类海报动效的分类：商品旋转、角标脉冲、文字逐字出现，覆盖了电商海报最常见的三种动法。
