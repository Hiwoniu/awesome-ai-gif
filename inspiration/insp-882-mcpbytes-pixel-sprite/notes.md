# 笔记

## 它是怎么做的

这是一个跑在本地 GPU 上的开源引擎，也能以 MCP 服务器形式接进 Claude、Cursor 等客户端。输入一句话描述或一张参考图，输出一张 128×128 的像素精灵表：16 个 32×32 的格子，四行分别朝下、左、右、上，每行三格是行走姿势、最后一格是待机姿势（举手、左右跳、躺下）。每次生成附带帧 PNG、四个方向的行走循环 GIF、QA 元数据，以及 Godot 4 场景和 Unity 6 导入器；manifest 里写清帧矩形、支点、调色板与 QA 状态。模型是 FLUX.2 加像素表 LoRA，权重从 Hugging Face 按固定版本拉取；同一种子、同硬件、同设置可以逐字节复现。行走预览的播放顺序是第 0、1、2、1 格循环，不是四格直放。QA 状态只有“未审”与“待审”，不替人背书，仍要人工检查解剖、朝向与透明度。

## 我们怎么用

借它的表结构与交付组织：游戏向精灵表可以按“四方向行走加四种待机”排布，一张表同时给 GIF 预览与引擎导入两种出口。manifest 写帧矩形与 QA 状态的做法值得抄：我们的精灵表也可以附一份小清单，记格子位置、帧时长与检查结果，方便以后复用。种子可复现这一点对做系列角色有用：同一角色换动作时固定种子，减少漂移。注意它要英伟达 GPU 或走云端，Mac 本地跑不了，只能借结构，不能直接拿来跑。
