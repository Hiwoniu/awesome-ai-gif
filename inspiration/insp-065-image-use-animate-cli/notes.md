# 笔记

## 它是怎么做的

- 一个零依赖 Python CLI：用已有的 ChatGPT 订阅（免费版也行）驱动网页版聊天生图，也能走 Codex 或 Gemini 订阅，不用单独买 API Key。
- animate 命令：让模型画一张严格 4×2 的精灵表，裁成 8 帧等大的图，校验主体有没有漂移，再拼成往返循环，默认出 WebP，加参数可出 GIF；源精灵图会留在动画旁边。
- 动画后处理需要 ImageMagick，WebP 输出还要 libwebp。

## 我们怎么用

- 借它用订阅当后端的工具形态：本地出 GIF 不一定走 API 计费，订阅驱动也是一条路。
- animate 命令的设计值得学：严格格表、裁帧、漂移校验、往返循环，四步串成一条命令。
- 往返循环（ping-pong）是直出 GIF 之外的另一种循环做法，动作来回走时比首尾硬接更顺。
- 只借命令设计，不直接搬工具；用前先核对仓库里的协议。
