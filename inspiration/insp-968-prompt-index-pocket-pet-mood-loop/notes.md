# 笔记

## 它是怎么做的

- 以一张宠物照为唯一身份参考，用 GPT Image 2.6 一次生成一张 3×2 精灵表，六格分别是：开心弹跳、好奇歪头、困倦蜷缩、惊讶小跳、轻轻挥手，最后回到开场的中性姿势。
- 提示词把身份锚点逐项锁死：灰虎斑花纹、蓝色头巾、眼睛颜色、身体比例、柔软立体的 3D 材质、奶油色背景、机位、比例和光线，每格都一样。
- 循环闭合靠最后一格回到开场姿势实现；同时要求动作在贴纸小尺寸下仍可读，禁止文字、Logo、水印、多余动物和身份漂移。
- 页面附一张六格示例图（六种一致的 Q 版猫咪情绪），2026-11-07 更新，标注为 ChatGPT / Image 2.6 适用。

## 我们怎么用

- 借六格一格一情绪的分组法：做微信表情包时先定六个高频情绪，一次出齐一系列表情，再逐格切帧拼循环 GIF，比单张单张生成更省事、角色更稳。
- 借身份锚点的清单式写法：换我们自己的原创角色时，同样逐项列花纹/配饰/配色/材质/背景/机位/光线，避免多格串貌。
- 借末格回开场的闭合要求：每套表情的最后一格固定回中性姿势，循环不断。
- 不照搬示例猫咪形象和原文措辞，角色、情绪组合、配饰全部换原创。
