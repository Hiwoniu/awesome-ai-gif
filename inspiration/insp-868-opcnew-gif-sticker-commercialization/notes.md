# 笔记

## 它是怎么做的

文章的论点是：Images 2.6 让 GIF 生成变容易了，但工具解决的是生产流程，不是版权与变现。文中介绍的开源 Skill 把整套活拆成可复用的固定步骤：角色定稿、聊天场景、动作分镜、字体、文件导出，可在 Claude Code 或 Codex 里跑。给出的实用方法有三条：先定角色、少量出样、动作验证通过后再扩成整套；文字单独成层，避免字形在帧间漂移；记住 GIF 本质是按顺序播放的图片序列，每张有自己的显示时长。风险部分同样实在：Skill 改善不了自然过渡与透明背景这类生产细节；成品仍是关键帧动画，部分效果靠重复帧；变现前要核对原始角色、字体、肖像与生成工具条款，AI 重绘不等于拿到销售权；微信表情开放平台与电商平台的准入要求各不相同。

## 我们怎么用

用自己的原创角色重做时，借两点：一是五段工作流的拆法（角色定稿→场景→动作分镜→字体→导出），把它当作我们做表情包的检查清单；二是“先定角色、小批量验动作再扩整套”的放量节奏，避免一次出整套再返工。三是版权检查清单直接可用：我们只用原创角色、核对字体授权、按微信表情平台的规格交付。文中提到的开源 Skill 没有给仓库链接，落地前要另找对应 Skill 核对，不要凭这篇文章直接认领。
