# 笔记

## 它是怎么做的

ComfyUI 里用 AnimateDiff Evolved 节点把静态图变动起来：静态图经 VAE 编码，用去噪控制加动作；去噪 0.3-0.5 能保住品牌一致性又看得出动；提示词超过 75 个 token 会中途换场景；帧插值每对帧之间插一帧，顺滑度翻倍；低显存启动参数能让 6-8GB 显卡跑起来，只是慢 2-3 倍。还给了工作流 JSON 与常见报错排查。

## 我们怎么用

借去噪区间、token 上限、帧插值这三条参数经验。做产品图与品牌素材动效时，去噪先从 0.4 起试，提示词压在 75 token 内，输出后再插值提顺滑。闭环循环的检查清单可以并进我们的验收流程。
