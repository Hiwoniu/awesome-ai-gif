# 笔记

## 它是怎么做的

工作流用 Wan 2.2 FP8：高低噪声两个扩散模型、文本编码器、VAE 与两个 Lightning LoRA，workflow JSON 可直接拖进 ComfyUI。同一张图既当首帧又当末帧（first-last-frame 节点），16:9 用 832×480，65 帧约 4 秒；提示词只写循环类动作（头发摆动、衣物起伏、漂浮物、环绕镜头、环境动效）。高低噪声 K 采样器各 4 步，VAE 解码后 RIFE 补帧提顺滑，再用颜色匹配以原图为参考稳住光线，最后删掉最后一帧避免首尾重复。低显存有 GGUF 版（换 UNET 加载节点）。防抖技巧：关高噪声 LoRA、步数提到 10-20、结束步设一半、CFG 从 1 提到 3 左右。

## 我们怎么用

借首尾同帧的循环做法：动态海报或长循环 GIF 可以先用视频模型出循环片段再转 GIF；提示词只写循环类动作的取向可以直接套。
