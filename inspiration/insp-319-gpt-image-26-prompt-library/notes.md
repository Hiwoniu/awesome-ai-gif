# 笔记

## 它是怎么做的

这是一个部署在 Cloudflare Workers 上的个人提示词库，共 98 条，每条独立成页、带复制按钮和成品示例。库按用途分了图、GIF、SVG 三类，GIF 类每条都固定标注帧数与时长（多为 8 帧×200ms、约 1.6 秒），并注明是否需要参考图。GIF 模板覆盖几类典型写法：参考图人物反应（戴墨镜点头、吃饭抬头）、中景海报微动（樱花飘落、富士山静止）、360° 转盘（战士、运动鞋）、吉祥物循环（机器人挥手、柴犬开心舞、狐狸伸展）、像素风（雪夜猫）。结构上每条都是“主体锁定 + 一个小动作 + 回到起点 + 镜头固定 + 帧数时长”的固定骨架。

## 我们怎么用

拿它当“动作—帧数—时长”对照表：想做哪类 GIF，先看同类模板的帧数与时长档位，再按我们自己的角色与动作重写提示词。分类方式也可以借：反应类、转盘类、吉祥物类、像素类、海报微动类，分开建我们自己的模板库。注意只借骨架与分类，不照搬库里的具体角色、文案与提示词原文；库里个别条目疑似改编自官方示例与社区帖，用的时候要再核对。
