# 笔记

## 它是怎么做的

一套 16 张的表情套系：9 张静态打底，7 张 GIF 点睛。角色是“屏幕脸”——一张屏幕当脸的极简设定，表情变化靠屏幕上的图案和少量肢体动作完成。静态负责覆盖常用情绪和场景，GIF 只用在最需要动效的几张上，动静搭配控制了整体制作成本。

## 我们怎么用

借它的套系结构：做我们自己的原创角色套系时，也可以先定 16 张左右的情绪/场景配比，静态打底、GIF 点睛，不必张张都动。极简角色（屏幕脸这类）的思路值得参考：表情变化不靠五官细节，靠图形符号和动作，换我们的原创角色同样成立。TRAE宝是官方吉祥物 IP，只借结构，绝不复用该角色。
