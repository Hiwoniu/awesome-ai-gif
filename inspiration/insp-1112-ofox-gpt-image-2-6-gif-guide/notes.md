# 笔记

## 它是怎么做的

一篇系统教程，三条路径并列：ChatGPT 对话里直接出、Images API 调参数出、精灵图合成出。提示词按六段式组织：输出格式、主体、动作路径、固定项、画风、验收。动作写法强调“一个来回、首尾帧一致”，这是循环不断裂的关键。API 路径给出了帧数 2–64、帧时长等参数表，还有 GIF 验收检查脚本和 FFmpeg 压缩命令。附了一次 Flare 原生 GIF 实测：9 帧 × 200ms。

## 我们怎么用

借它的六段式提示词结构和三条路径的对照表：我们自己的教程和 Skill 可以按“对话 / API / 精灵图”三条路径分开写，每条路径给一套参数起点。验收清单（尺寸、帧数、时长、循环元数据逐项核对）可以直接做成我们出品前的自查表。只借结构与参数思路，不抄它的提示词原文和示例图。
