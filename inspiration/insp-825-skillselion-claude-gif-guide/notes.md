# 笔记

## 它是怎么做的

指南把几个 Claude GIF Skill 列成对照表：slack-gif-creator、gif-sticker-maker、mermaid-to-gif（流程图变动效）、claude-gif-generate（给 Veo 3.1 写静态背景加自然重复的循环提示词），按安装量与星标排序并注明各自适用场景。

## 我们怎么用

我们选 Skill 时借它的对照表做法：先列候选、再按安装量与星标筛，最后按场景定；mermaid-to-gif 与 Veo 循环提示词两条非贴纸路线可单独记下来备用。
