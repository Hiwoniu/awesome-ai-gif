# 笔记

## 它是怎么做的

以一张虚构演出海报 AFTERIMAGE 为例，演示静态海报如何转成 16 秒无声动态稿。做法分三步：先定海报的层级——什么必须一眼认出来（这里是两行大标题、墨色加荧光绿的配色、同心圆图案）；再给每个元素分工：标题负责第一时间立住身份、同心圆图形负责动效与氛围、一段简短文字负责念出 SOUND / LEAVES / A TRACE、结尾回到原海报并把演出信息定格至少三秒；最后用可复用的提示词把设计转成动效简报，在 Remotion 工程里实现，文字保持可编辑的文本与 SVG 形状，而不是画死在图里。

关键约束是“一个动效主线”：如果标题、装饰、日期、背景同时抢戏，海报就散了；只让图形动、文字让路，动效才有阅读顺序。附带的工程包含字体与源文件，改日期不用重画。

## 我们怎么用

动态海报直接套用这套分工法：先列出海报上不能丢的三样（标题、信息、配色/图形），再定一个动效主线，其他元素只做配合；结尾回到原海报定格几秒的收尾法，可以让动态海报在循环播放时不显得突兀。文字保留可编辑源文件这一点也值得学——海报上的字不要画死，方便改期、改场次。成品是 MP4 不是 GIF，只借结构与分工，不照搬实现。
