# 笔记

## 它是怎么做的

作者的流程分两步：先让 ChatGPT 一次画出 3×2 的六格分镜图，约束是同一角色、同一位置、只动一个部位、末格接回首格；再让 Claude 写脚本，按白色格线自动切图并合成无限循环 GIF。细节上强调首格要能单独成立、格线用白色方便程序识别，另外还给了一段可直接贴进网页的横条动画代码。

## 我们怎么用

借“六格同生保一致 + 格线辅助切图 + 只动一个部位”的结构，换成我们自己的原创角色重做；切图脚本的思路可以沉淀成我们自己的小工具。网页横条动画是池内少见的交付形态，做动态海报时可以参考。
