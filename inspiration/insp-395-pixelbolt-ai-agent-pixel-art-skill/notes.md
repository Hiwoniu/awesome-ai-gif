# 笔记

## 它是怎么做的

这个 Skill 不直接出图，而是把像素画和动画写成一份 JSON 配方：每帧的像素、调色板、帧顺序都在文本里，渲染是确定性的；agent 改配方就能改帧，改完读回像素自己检查对齐和颜色，再继续改。导出支持 PNG 精灵表、动画 PNG、GIF 和逐帧图，本地跑 MCP 或 CLI，不用 API key。

## 我们怎么用

借它的“配方即动画”做法：我们的像素风表情包也可以先定一份帧配方（帧数、尺寸、调色板、每帧动作），生成后逐像素自查再改；做 Skill 时参考它把动画写成可编辑文本的形态，角色换成我们自己的。
