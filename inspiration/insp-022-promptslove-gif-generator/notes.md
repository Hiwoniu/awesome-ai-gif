# 笔记

## 它是怎么做的

表单式提示词生成器：按 OpenAI 建议的五段式简报填表（场景、主体、细节、用途、约束），自动拼成提示词；内置循环 GIF 贴纸、环境产品循环等模板；GIF 模板固定写一个主体、一个小动作、回到起始姿势、镜头不动，并标出帧数 2-16、每帧 20-2000 毫秒的 API 参数范围。

## 我们怎么用

借它的五段式简报结构：我们的提示词公式也可以按场景、主体、细节、用途、约束五段组织，比自由发挥更稳定。循环 GIF 贴纸模板的固定套路（一个主体、一个小动作、回起始姿势）可作我们贴纸提示词的检查清单。
