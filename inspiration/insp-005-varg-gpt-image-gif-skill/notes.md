# 笔记

## 它是怎么做的

- 用 varg 的 output_format=gif 直出真 GIF；整理了 sprite-sheet 像素预算表，标出 2/4/6/9/12/16 帧各自能用的帧尺寸。
- 工作流：先批准一张静态图，再让它动；提示词模板强调一个简单动作、首尾同一休息姿势、每帧同尺寸同位置同地平线、固定镜头、背景不变、无文字。
- 还记录了失败模式：帧里出现文字、动作太快、背景沸腾；后处理脚本把 GIF 转 WebP/MP4。

## 我们怎么用

- 对照我们的机检和提示词：补像素预算实测、补失败模式清单。
- loop-lock 措辞用我们自己的话重写进 prompts，不抄原文。
