# 笔记

## 它是怎么做的

Skill 把一张用户照片（人物、宠物、物品或 Logo）变成 4 张 Funko Pop / Pop Mart 盲盒风动态 GIF 贴纸，渲染成 C4D / Octane 3D 手办质感，白底工作室背景、底部黑字白边字幕。默认四张为开心挥手、大笑、哭泣、比心；字幕可由用户指定 1–3 个词，或按检测到的语言从多语言字幕表取。管线分三段脚本：MiniMax 图像生成、图生视频动画、MP4 转 GIF，收尾有 deliver_assets 交付块；运行需要 Python 依赖、ffmpeg 与 MINIMAX_API_KEY。

## 我们怎么用

借三段式管线与四动作成套规划，用自己的原创角色重做；字幕对照表按语言配文案的思路可平移到中文表情包的文案管理。
