# 笔记

## 它是怎么做的

- 卡片是 3:4、圆角 18px、带深阴影；两张满幅图叠在一起，用同一套竖条纹遮罩交错：每条 6px 宽，前图占前半、后图占后半。
- 一个过渡变量 t 从 0 到 1：t=0 只看到前图，t=1 只看到后图，中间是两图细条交错的过渡，像真光栅片的翻面。
- 指针横向位置映射到 t，中间三分之一做平滑过渡，所以翻面发生在拖动的中段，而不是一开始就跳变。
- 组件是 React 加 TypeScript，自带设计说明与提示词，意思是这套做法可以直接拿去重新生成或改写。

## 我们怎么用

- 借它的条纹交错实现：做光栅变画卡时，两张图的交错可以用 6px 竖条纹这个具体数值起步，再按卡片尺寸调。
- 指针驱动的过渡思路可以用来做网页演示版：拖动看翻面，比静态 GIF 更能讲清光栅效果。
- 同卡两面的构图（白天与夜晚同一海报）可以直接套到我们自己的角色与场景上。
- 不直接搬对方的组件代码与示例图，只借条纹与过渡写法。
