# 笔记

## 它是怎么做的

这是一份比赛作品的完整工程报告，不是只发图的展示帖。做法分四层：先用一张 4×4 体素风角色表定住角色（青色荧光像素眼是唯一恒定记忆点），再把每枚表情拆成人物层和文字层两个动态层——文字横幅、爱心、Zzz 不再跟着人物一起僵硬运动，而是有自己的浮动、摆动、闪烁节奏，与人物动作错相位叠加。16 种动作全部语义化编排：惊慌是高频抖动、躺平是缓慢漂浮、得意是心跳脉冲，每种动作都给了人物层和文字层各自的幅度参数。技术上抠图分层、频率整循环对齐（12 帧/12fps=1 秒）、还处理了高频正弦在 12fps 下采样恒为 0 的奈奎斯特问题；编码用 GIF89a（128 色中位切分 + LZW + 透明 + 无限循环），最后逐枚核验体积与帧间变化量，16 枚全部 ≤500KB、240×240。

## 我们怎么用

最值得借的是“人物层 + 文字层分离动效”这个结构：以后做带字表情时，文字不再贴死在人物身上，而是单独给浮动/闪烁节奏、与人物错相位，能立刻让画面活一倍。其次是它的验收方法：逐枚记体积、记帧间变化量、12fps 下检查高频动效是否被采样吃掉，这些都可以直接抄进我们的试做检查表。角色是 TRAE 的官方吉祥物，绝不能照搬形象与文案——只借分层结构、动作语义化编排和编码组合，换我们自己的原创角色与文案重做。
