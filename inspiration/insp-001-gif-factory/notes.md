# 笔记

## 它是怎么做的

- 九类：表情包（像素、插画动作、真人照片、宠物照片、黏土吉祥物）、光栅变画卡、动态海报、动态签名、电影片头、文章封面配色、动态绘本、品牌短片、知识大赏。
- 光栅卡 480×720、6 秒、20fps：A 停留 → 竖条过渡 → B。动态海报是两态双联图。
- 根目录一个总入口，子 Skill 可单独装。

## 我们怎么用

- 只收产物是 GIF 的类型；电影片头（静态）、配色（非动图）、短片和知识大赏（视频）不收。
- 用橘团重做，不碰它的 IP 案例。已做：`trials/2026-11-18-gif-factory-styles/`、`skills/two-state-gif/`。
