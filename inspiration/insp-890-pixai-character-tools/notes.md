# 笔记

## 它是怎么做的

一次上线四款角色工具，入口都是“上传一张角色图”。Q 版动态贴纸给四个预设动作（吃零食、欢呼、弹出、捏脸颊），也可以自定义动作；像素精灵表给待机、跑、攻击、跳舞四个预设动作，同样支持自定义。另有矢量 Logo 生成器（贴纸、线稿、Q 版三种风格）和一键去背工具。两条 GIF 路线都产出循环 GIF，适合聊天和社交媒体。

## 我们怎么用

借它的动作库组织方式：给原创角色定一套“四个预设动作 + 自定义动作”的动作表，表情包和像素风各一套，动作名先定好再批量生成。Q 版贴纸路线适合微信表情包，像素精灵表路线适合游戏风小动画；两个路线共用同一张角色图，形象一致性好做。不照搬它的示例角色和动作名原文，按我们自己的角色重写。
