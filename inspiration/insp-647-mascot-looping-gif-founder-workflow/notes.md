# 笔记

## 它是怎么做的

先定吉祥物或产品图的静帧并用保存的参考图锁定角色，再一句话描述一个小动作要循环 GIF；要速度、快速迭代时选 Flare，要跨多次编辑保持角色一致时选 Sunburst；出片后直接放进 Framer 做 hero 或栏目点缀，短循环、无声、手机上可读；注意 ChatGPT 不能对已上传的 GIF 二次编辑，改动要在原对话里重做。

## 我们怎么用

借它的落点思路：我们的 GIF 按产品站 hero、栏目点缀、聊天反应分三档定规格；Flare 与 Sunburst 的选型写进出图前的模型选择清单。
