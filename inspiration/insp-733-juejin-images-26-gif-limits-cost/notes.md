# 笔记

## 它是怎么做的

文章按可信度分层拆解：先算成本账（低画质档单张 token 从 196 涨到 823，约 4.2 倍，单价不变但用量翻倍），再划 GIF 的能力边界——帧数与帧时长区间、3 秒 24fps 需要 72 帧因而超上限、只挂在文生图端点、编辑端点不支持、不能传参考图；最后给选型建议，Flare 试效果、Sunburst 保多轮一致性，complexity 分三档管生成前的规划力度。

## 我们怎么用

借它的边界推算当验收上限：短循环只做一个主体、一个动作、机位不动；按帧数与帧时长先算好总时长再动手，不照抄有争议的上限数字，落地前以自己账户的实际校验为准。成本上批量跑低画质小图前先压测。
