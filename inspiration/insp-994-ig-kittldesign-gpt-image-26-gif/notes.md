# 笔记

## 它是怎么做的

设计工具 Kittl 把 GPT Image 2.6 的 GIF 功能接进了自己的品牌图库。演示流程很短：从“你的品牌图”里挑一张静态品牌图，选 GPT Image 2.6 GIF 模型，写一句动作提示，设 3 秒时长，点生成。示例是粉色沙漏：沙子流下、沙漏翻转、回到起点，循环干净。视频里还演示了另外三张品牌图（叠石、肥皂、糖果机）同样转成循环 GIF。

重点在投放：同一张 GIF 接着出现在 IG 帖子、品牌官网首页、补货邮件里，等于是“品牌图进、GIF 出”，一次制作三处复用。结尾口号就是这个意思。整个演示没有旁白，只配音乐，突出的是操作少、能直接发。

## 我们怎么用

借“一张品牌图+一句动作提示+3 秒”的极简输入做动态海报：我们的原创角色或产品静帧先定稿，动作只写一个可逆过程（如沙漏式流下再翻转回位、产品转一圈回正、光影扫过再回来）。投放上学它的一图三用：同一张循环 GIF 同时当 IG 帖子、官网首屏动效、邮件上新配图，省掉三处各做一版的成本。注意这是设计工具里的功能演示，不是独立教程，动作提示的具体写法要按我们自己的角色重写。
