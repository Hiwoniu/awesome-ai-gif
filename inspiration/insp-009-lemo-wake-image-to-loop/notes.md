# 笔记

## 它是怎么做的

- Claude 先读图，把画面拆成文字、形状、物体、人物和光，再用代码重建各部件并为这张图单独编舞。
- 在无头浏览器里渲染帧，尾帧接回首帧，编码出 MP4/GIF/WebP/Live Photo；GIF 上限 5MB、宽不超 1080，另有 240px/≤500KB 的微信表情规格。
- 不用生图模型、不用 API Key，全本地。

## 我们怎么用

- 对动态海报和动态签名特别有启发：文字和笔画用代码画，比让模型画字稳。
- 可以先拿一张橘团海报试它的思路，评估是否给 two-state-gif 加一条代码路线。
