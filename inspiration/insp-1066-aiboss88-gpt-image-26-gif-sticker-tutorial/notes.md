# 笔记

## 它是怎么做的

全流程分三段：一句话生成单张动态表情包，提示词结构是角色参考、动作过程、约束条件、输出规格四部分，输出 240×240、500KB 以内、约 3 秒的循环 GIF；结合 GitHub 上的 ray-sticker-shop Skill 成套出图，Skill 自动按微信规格调尺寸与体积；参考 GIF 换主角二创：动作、镜头、节奏取参考 GIF，外观取角色图。经验是动作越聚焦越丝滑，贪大动作容易瞬移或肢体崩坏；单次生成 1.5–2 秒、9 帧比较合适。

## 我们怎么用

照四段式提示词结构给自家原创角色写起手句式；成套出图时试一次 ray-sticker-shop Skill 的流程；参考 GIF 换主角的做法只借方法，参考素材用我们自己的动图。
