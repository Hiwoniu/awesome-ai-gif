# 笔记

## 它是怎么做的

Skill 先按控制需求分流：像素循环或 VFX 走专用动画模型（同种子精灵表重跑+切片）；要精确网格、指定帧数、编排节拍走高 adherence 通用图像模型（一次 model_run+切片+逐 tile 对齐+组装）；无缝循环走首尾帧视频模型（同一静帧放两端+明确动效语言+抽帧+接缝检查）；指定时刻姿势走关键帧视频模型。网格规格要点：行列在切片器 6×6 上限内，16 帧用 4×4（不用 2×8）、画布能被网格整除、同一比例/机位/朝向/地面基线、末帧与首帧同姿、留白充足、无标签。关键经验：对齐是后处理步骤——实测中同一角色的脚在末行比首行高 87px，提示词与布局模板都纠不过来，只能量每 tile 的身体框、移到同一基线与水平中心；GIF 帧延迟按 10ms 量化，fps 取 10/20/25 才不被重定时；抽帧顺序不可假设，须用首末帧对照核对。另有方向循环路线（多朝向行走/跑/待机/攻击）与三段本地脚本。

## 我们怎么用

做精灵表类 GIF 时借它的分流表：先判断要精确网格还是像素循环，再选路线；网格提示词按它的规格写（4×4、末帧回首帧、留白）；验收时加两项：逐 tile 对齐检查与 fps 取 10/20/25；抽帧后先核对顺序再拼。
