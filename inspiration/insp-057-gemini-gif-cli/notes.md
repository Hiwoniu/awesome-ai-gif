# 笔记

## 它是怎么做的

- 一个 Python 命令行工具，用 Google Gemini 2.0 Flash 模型按文字提示词生成动画 GIF。
- 提示词模板可以自定义参数传进去，相当于把“主体加动作加风格”的写法固定成模板再填空。
- 通过 pip 安装，需要一个 Gemini API Key，MIT 协议开源。

## 我们怎么用

- 借它 Gemini 路线的模型选择：当 GPT 路线不可用或想换个模型口味时，可以拿这个工具做对照测试。
- 提示词模板参数化的做法可以学：把我们自己的提示词结构也做成可填空的模板。
- 工具是 2025 年 3 月的早期版本，先小规模试效果再决定是否纳入工作流。
