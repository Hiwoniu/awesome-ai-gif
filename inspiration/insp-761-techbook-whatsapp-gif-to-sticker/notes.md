# 笔记

## 它是怎么做的

TECHBOOK 针对 X 上流传的一个说法做了实测：有人说只要复制 GIF 的“视频链接”、粘贴到 WhatsApp 就能变成动态贴纸，帖子还附了社区备注质疑这个说法。

实测结果是链接那条路行不通。真正管用的做法是：先把 GIF 像平时一样发到 WhatsApp 聊天里，再长按这条已发送的 GIF 复制，重新粘贴到输入框发出去，WhatsApp 会把它自动转成动态贴纸，之后可以收藏进贴纸栏反复用。动画在转换后保留了下来。安卓端文中只转述了 Gboard 或 WhatsApp 自带编辑器的替代做法，没有实测。

## 我们怎么用

借它的分发思路，不借它的截图和文案：

- 分发可以多一条路：我们做好的循环 GIF，除了发微信表情包，也可以按这个办法进 WhatsApp 贴纸栏，等于多一个使用场景。
- 验证方法可以学：网上流传的“捷径”先自己在真机上试一遍再写进教程，别直接转述。
- 反例有提醒价值：复制链接和复制 GIF 本体是两回事，写分发教程时要把这点讲清楚，免得读者照着链接那条路走不通。
