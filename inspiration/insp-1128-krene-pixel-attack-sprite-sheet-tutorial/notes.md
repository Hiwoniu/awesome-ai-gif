# 笔记

## 它是怎么做的

用 Nano Banana Pro 做像素风角色攻击技能的序列帧：拿一张已有的精灵图当动作骨架参考，替换成目标角色，但严格保留帧的位置、大小、排列和动态趋势，最后导入 PS 时间轴合成 GIF。关键是“骨架复刻、只换皮囊”——动作的节奏和帧结构不变，变的只是角色外形。

## 我们怎么用

借它的换皮方法论：我们做新动作（攻击、跳跃、挥手）时，可以先找一个动作骨架参考，定好帧位置和排列，再换成我们自己的原创角色。这样动作节奏有保证，又不照搬别人的角色。提示词里“帧位置/大小/排列严格一致”的约束写法可以直接借进我们的精灵表提示词模板。参考精灵图本身不复用。
