# 笔记

## 它是怎么做的

六段视频轮播演示 Lottie Creator 里的 Motion Copilot AI 工具：输入文字提示词（如 Animate the eclipse drifting through space… Preserve all artwork），模型（Opus 4.8 / Sonnet 5）生成循环动画（日食、礼盒弹跳、番茄等）。

## 我们怎么用

借它的提示词写法：提示词驱动动效时先描述动作、再加 Preserve all artwork 锁定原画；模型选型可以按 Opus 与 Sonnet 的分工来试。
