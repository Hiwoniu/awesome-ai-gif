# 笔记

## 它是怎么做的

Spritix 是 2026-11-07 上线 Product Hunt 的 AI 精灵图生成器：上传一张角色图，生成待机、行走、奔跑、跳跃、攻击五种动作的可复用 2D 动作库；生成后可以裁帧、调速度、精修循环，且精修不另花生成额度；导出支持精灵表、GIF、Atlas JSON 与 PNG 帧，适配 Godot、Unity、Phaser；带版本历史与按动作导出设置。免费额度是每月 20 点、每月可下载两次生成结果。

## 我们怎么用

用自己的原创角色重做时，借三点：一是“按动作建库”的组织方式——一个角色一次出 Idle/Walk/Run/Jump/Attack 五个标准动作，沉淀成可复用的动作库，而不是每次单张现做；二是逐动作导出结构（精灵表 + GIF + Atlas JSON + PNG 帧），同一套动作同时覆盖表情包与游戏素材两种交付；三是“精修循环不另花额度”的调参思路，先锁定动作再微调帧与速度。产品刚上架、无实测评价，收进来先当组织方式参考，实际效果要拿自有角色试过再定。
