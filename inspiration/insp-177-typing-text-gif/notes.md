# Typing Text GIF：纯前端打字机动画转循环 GIF

- 来源：GitHub · fancydirty · https://github.com/fancydirty/typing-text-gif
- 类型：signatures · 状态：pending 待审

## 它是怎么做的

纯前端小工具，在 canvas 上渲染打字机动画并编码成循环 GIF/APNG，无后端、不用 ffmpeg/WASM。
打字机动效的逐字时序与 GIF 透明描边处理经验，是动态文字类 GIF 的编码注意事项清单。

## 我们怎么用

只借类型、手法、构图、提示词结构，换原创角色重做；不照搬对方画面、角色、文案、提示词原文。具体可借的点：

- 打字机动效的逐字时序写法
- GIF89a 无半透明的描边光晕处理（按背景色做 matte）
- Outlook 只显示第 0 帧的兜底意识
