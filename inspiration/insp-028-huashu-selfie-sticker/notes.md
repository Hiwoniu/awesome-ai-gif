# 笔记

## 它是怎么做的

Skill 流程：上传自拍，先做一张角色设定图（透明底），再用同一张设定图一次画 4 列×2 行的八格精灵图，切帧拼 GIF；一共 8 个表情、每个 8 帧，字幕直接画在同一格里，作者称 8 套共 64 格零错字。安装方式是把 Skill 装进 Codex 后一句话调用。

## 我们怎么用

借它的 Skill 化流程：设定图、八格表、切帧、拼 GIF 四步固化成 Skill，调用一次出整套；字幕同格绘制的做法，适合我们的带字贴纸。注意它的输入是真人自拍，我们只借流程，角色一律换原创。
