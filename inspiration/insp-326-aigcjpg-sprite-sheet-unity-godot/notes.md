# 笔记

## 它是怎么做的

作者以一只小狐狸跑步循环为例，对比了两条做游戏精灵图的路线：图生图直接生成 4×2 精灵图；图生视频再拆帧、抠像、拼图。文章复盘了图生图路线帧间不连贯的成因与修补办法，给出三条对齐约束（格子等大、角色等大、脚底同一基线），并附一条 ffmpeg 抽帧抠像拼图命令，最后讲了导入 Unity 与 Godot 的步骤。

## 我们怎么用

借三条对齐约束和“为后处理而设计”的思路（纯色背景、固定网格、锁定镜头），换成我们自己的原创角色做游戏向精灵图；两条路线的取舍标准可以直接拿来做决策参考。
