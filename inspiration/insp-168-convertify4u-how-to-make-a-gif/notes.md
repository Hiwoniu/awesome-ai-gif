# 笔记

## 它是怎么做的

Gif Studio 全在浏览器本地跑：加两张以上 JPG/PNG/WebP 静帧或 MP4/WebM/QuickTime 短片，生成按钮要等满两帧才亮。播放方式四种：正播、倒播、回旋、往返播（出再回，适合短动作平滑重复）；裁切保持原形或 1:1、16:9；延迟默认 120 毫秒，可填 10-5000；质量滑块 1-30，默认 10，数字越小采样越细；循环默认开。帧拼在白色底上输出，最多 30 帧、最长边 1200px。教程强调：先按默认出一张看效果，再一次只调一个参数；原帧留着，二次生成比改已生成的 GIF 干净。

## 我们怎么用

借往返播的做法：只有一个小动作的 GIF 可以用往返播代替首尾对齐，省掉对帧的麻烦；“默认先出一张、一次只调一个参数”的调试纪律可以直接写进我们的试做流程。
