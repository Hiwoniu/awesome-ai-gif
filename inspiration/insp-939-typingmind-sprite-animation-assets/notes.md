# 笔记

## 它是怎么做的

Sprite Animation Assets 是 DwDestiny 的一个 Skill，面向 Codex 等 Agent，解决“连续帧动画素材”怎么做。核心判断是：动画素材的关键不是单张好看，而是同一角色或物体在每一帧里身份一致、尺寸一致、背景透明、动作能循环。工作流是：先定义规格（状态名、每状态帧数、画布尺寸、输出格式）；生成或确认一张 canonical base image 做所有帧的身份锚点；分状态生成连续帧，每组都用同一角色参考与同一纯色背景或透明策略；用脚本把帧拼成 atlas，并可导出每状态的 GIF 预览；最后看 sprite-set-report.json 做验收。

## 我们怎么用

借“规格先行、身份锚定、脚本组装、报告验收”的四段工作流：做成套连续帧素材时，先写清状态与帧规格，再锚定一张标准底图，分状态生帧后用脚本拼表并出 GIF 预览验收。换我们自己的原创角色，不照搬它的示例素材。
