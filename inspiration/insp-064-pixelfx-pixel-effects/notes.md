# 笔记

## 它是怎么做的

- 244 个像素风特效，每个都是一小段代码：火焰、爆炸、魔法、天气、UI、拾取物、小怪等，分门别类放在代码目录里。
- 特效可以在线试玩、换色、镜像，也能导出精灵表（透明 PNG 网格加帧信息 JSON）或直接导出 GIF 与 MP4。
- 角色类特效讲究表演结构：先蓄势、再出手、命中时定格、目标回摆、最后恢复，动作有起承转合。
- 配了一个 Claude Code Skill：按“起草、渲染、看效果、再改”的流程教 Agent 现做新特效。

## 我们怎么用

- 借它代码驱动像素动效的路线：像素风贴纸与海报的动效不一定靠生图，用代码逐帧算特效再导出精灵表也是一条路。
- 蓄势、命中定格、回摆、恢复这个表演结构可以直接套到我们自己的角色动作上。
- 导出精灵表加帧信息 JSON 的组织方式值得学，方便后续切帧与拼 GIF。
- 用前先核对仓库里的协议；只借路线与结构，不直接搬对方的特效代码。
