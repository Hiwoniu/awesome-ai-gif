# 笔记

## 它是怎么做的

在 Stable Diffusion 里加 AnimateDiff 运动模块做 GIF：底模型管画风，运动模块管动作，文生或图生都能出短动画。教程给的参数是运动模块选 v2、帧数 16 起、循环次数设 0 做无限循环，写实与卡通两种风格各给了一组完整设置。属于开源运动模块路线的实操版。

## 我们怎么用

借分层思路与参数取法。本地 SD 工作流做循环 GIF 时，底模型换我们自己的风格，运动模块单独选，帧数 16 起、循环设无限。写实与卡通共用流程这点说明同一套参数骨架可以跨风格复用。
