# 笔记

## 它是怎么做的

作者用自己的照片加 ChatGPT 做了一套 meme 贴纸包。做法是单张 1:1 方形透明底、3×3 九宫格、九种夸张反应（哭、懵、震惊、得意、斜眼、无语等），混搭 emoji，低保真剪贴质感，格子之间留宽透明间隔。提示词结构分四块：人物（以参考照片为准）、反应（九种情绪词）、风格（夸张表情、尴尬姿势、低保真剪贴、荒诞幽默）、版式（九格、透明间隔、无背景无重叠）。后续微调有三种句式：锁脸只改表情、逐个点名九种反应、按情境（如加班、等外卖）写反应；局部修改时点名“只改第二行中间那格”。

## 我们怎么用

借它的提示词四分法和九宫格版式：人物、反应、风格、版式各写一段；九种反应先按情绪词列清单，再按情境写一版对照；改图时一次只点名一格。角色换我们自己的原创角色，照片与真人形象不用。
