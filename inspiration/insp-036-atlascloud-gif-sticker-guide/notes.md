# 笔记

## 它是怎么做的

教程分三块：一是把一次生成拆成背景、角色与镜头、动作与收尾三段来写，动作段要求明确回到起始姿势；二是拿一只水獭做完整示例，验证这套结构能出可用的循环；三是把三组已发表的贴纸案例拿来对照，讲纯色底 GIF 和聊天软件贴纸格式的区别。导出部分强调先定发布渠道：能直接发的用纯色底 GIF，要进 GIPHY 或 WhatsApp 的再转对应格式，透明底和 GIF 格式不能同时兼得。

## 我们怎么用

借三段式提示词结构和先定渠道再定格式的决策顺序。换我们自己的原创角色重做：水獭换成橘团这类自有角色，背景色与动作按我们自己的贴纸风格定。导出时先想清楚这张贴纸发在哪，再决定要纯色底还是透明底。
