# 笔记

## 它是怎么做的

一个 TypingMind 上的 Skill，提供两条生成循环 GIF 的路线：一条是写 CSS 动画（单文件 HTML 加内联 CSS），用 Playwright 加 Web Animations API 逐帧抓取再合成 GIF；另一条是 Kling 图生视频。默认 800×800 画布，内置 6 种动画类型和循环参数表。

## 我们怎么用

借 CSS 动效转 GIF 的流程：我们的动态海报如果先有网页版动效，可以照这个思路逐帧抓取成 GIF，不用再逐帧画。只借流程与参数写法，换自己的原创角色与画面。
