# 笔记

## 它是怎么做的

- 公式：宽景或角色剪影 + 慢速环境动效 + 氛围/光影细节 + 风格 + 柔和无缝循环。动的是头发、衣摆、光，不让主体做大动作。
- 平台实测：X 主页头图上传后会被压成静态图，GIF 只能在帖子里动；头图推荐 1500x500（3:1）。
- 工具侧提供 chibi/anime/pixel/sticker/loop 等风格的 GIF Maker，思路可参考，工具本身不依赖。

## 我们怎么用

- 给动态海报加一个宽幅变体试做：橘团站在场景里，只动光影和衣摆，3:1 构图。
- 发 X 传播时记住：海报 GIF 发帖子，不指望头图位动起来。
