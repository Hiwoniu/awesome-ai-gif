# 笔记

## 它是怎么做的

本地导出流程：先拿到分开的、构图一致的 PNG 帧，再用导出脚本定顺序与时长拼成 GIF；示例跑通的是 320×180、12 帧、1.2 秒的循环 GIF，并输出一份检查报告记下环境与成品属性。文章还提醒：拿到的是联络表要先验格子是不是干净的 3 列×2 行，格子不齐不能靠等分裁剪硬修。

## 我们怎么用

借它的导出与校验流程：生成之后本地拼 GIF、写检查报告的做法，可补进我们的交付步骤；验格表的要点（格子等大、无多余标题、无越格作画）可作切分前的检查项。文章把实测与未验证分开标注的写法也值得学。
