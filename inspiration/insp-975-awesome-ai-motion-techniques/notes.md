# 笔记

## 它是怎么做的

一份开源的动效 field guide（GitHub，2026-09-30 建仓，367 stars）：637 种动效技法、128 条参考 clips、11 个 recipes、7 条 design routes。每种技法一张 effect 卡，含定义、调参、示例和给 Claude Code / Codex 的提示词；每个特效可以在本地渲染出 preview.gif / clip.mp4 / poster.jpg，原作 MIT。另附一个 Agent Skill，Agent 可以按“场景要传达什么”来选动效。

## 我们怎么用

做动态海报与卡片时，先按场景意图查它的选型表（比如产品亮相、标题开场、数据故事），再按 effect 卡的默认参数渲染一个 preview.gif 验收。只借动效选型与卡片结构，效果本身用我们自己的画面重做。
