# 笔记

## 它是怎么做的

一篇通用制作指南，流程是四步：先选一个可循环的动作，再按五要素写提示词（主体、动作、视觉风格、机位、循环行为），然后检查首尾帧连续性，最后做帧率、尺寸与体积优化。示例是一个 16-bit 像素雨夜咖啡馆动图：多元素微动，但动作设计原则是“一次只动一个元素”，其余元素只做极小幅度变化。还附了一份常见错误清单和一个免费 GIF 提示词生成器工具链接。体积控制给了一条链路：降尺寸、减色数、降帧密度、调速。

## 我们怎么用

把“提示词五要素”当作我们各类型 GIF 的提示词骨架：写任何一条提示词前先填满主体、动作、画风、机位、循环方式五格，缺一格就补。验收环节照搬首尾帧连续性检查：出图后先比首末时刻的角色、光线与机位有没有跳变。体积优化链路留着当发版前的固定动作：先降尺寸和色数，再动帧密度。
