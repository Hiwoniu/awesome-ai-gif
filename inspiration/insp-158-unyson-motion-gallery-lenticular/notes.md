# 笔记

## 它是怎么做的

Motion Gallery 把图片包进 3D 场景做动效画廊，其中光栅卡设计是：一张脊纹卡片，每条脊一面贴一张图、另一面贴下一张，转动卡片就逐张翻图；指针移动时卡片向指针方向倾斜，访客自己翻图。参数有脊纹数 10-60、倾斜 15-50°、卡片尺寸、移动时间、框色、光照、卡片比例与圆角。另有 33 个 WebGL 真 3D 设计（真光影、粒子、破碎玻璃等），与较轻的 CSS 3D 两档。

## 我们怎么用

借指针映射翻面变量的交互写法：数字端光栅卡演示可以用指针位置驱动混合变量；脊纹与倾斜角度的取值范围可以直接当参数起点。
