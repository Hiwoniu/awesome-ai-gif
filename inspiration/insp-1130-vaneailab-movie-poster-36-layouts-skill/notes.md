# 笔记

## 它是怎么做的

X 上分享的一个 Skill：用 GPT 做电影级海报，一次给到 36 种版式，开源分享。版式是核心资产——同一张海报主题，36 种排版方式各出一版。

## 我们怎么用

借它的版式清单思路：我们做动态海报时，也可以先沉淀一套版式库（居中式、对角式、满幅式、留白式……），再给每个版式配动效方案。Skill 的提示词组织方式（版式描述怎么写、怎么让模型稳定出某种版式）值得对照我们的海报提示词模板。只借版式分类与组织方式，不抄它的提示词原文。原帖未打开核实，待已登录 Chrome 复核。
