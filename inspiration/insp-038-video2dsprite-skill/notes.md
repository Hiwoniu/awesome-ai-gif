# 笔记

## 它是怎么做的

这是 agent-sprite-forge 里的一个 Skill，路线是先用 Grok 的图生视频功能让一张角色静帧原地动起来（6 秒或 10 秒），再从视频里抽帧、抠纯色背景、采样归一化，最后拼成条带、网格或 GIF。定位是密帧动作的补充路线：跑步、行走这类连续动作靠逐格画很难画顺，从视频里取帧更自然。作者明确区分了两条线： crisp 的像素表走逐格画，密帧动作走视频路线。

## 我们怎么用

借视频先行再抽帧的路线思路。我们的角色如果要做跑步、行走这类连续循环，可以先让视频模型跑出动作再抽帧，而不是一格格硬画。注意这个 Skill 只在 Grok Build 环境能跑（需要它的图生视频工具），在 Claude Code 或 Codex 里跑不了，收进来是留个路线参考。
