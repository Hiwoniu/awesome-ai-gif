# 笔记

## 它是怎么做的

这篇文章不教操作，只做核查：把官方说法、报道数字和“尚未证实”分开写。速度上，官方称比 2.5 快 50%，但引用的 Flare 实测基准是从 7.08 秒到 4.84 秒，约 32%，两者并列标注，不把 50% 当实测结论。定价上，报道的 API 价在官方定价页未上架前只记为传闻，提醒先等官方页或自己账号确认再做预算。模型分工上，Flare 定位速度、Sunburst 定位质量与跨改一致性；保存参考图被点为最值得注意的功能，但一致性与肖像存取权限同样标注为“宣称、未独立验证”。

## 我们怎么用

借三条纪律：一是做成本核算时只用官方页数字，传闻数字先记为待核实；二是批量试效果用 Flare、终稿用 Sunburst 的分工；三是把“宣称 vs 实测”对照写进我们自己的案例验收记录，数字注明出处，不直接引用厂商 headline。
