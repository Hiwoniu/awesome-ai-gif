# 笔记

## 它是怎么做的

扩展在 A1111 的文生图/图生图面板里加一个折叠面板，运动模块给冻结的生图模型注入时间注意力，一次生成一串连贯的帧。循环主要靠 Closed loop 一档：N 不循环；R-P 把帧倒序拼回去、不重复转折帧；R+P 倒序带重复帧；A 追加倒序帧做无缝循环，指南推荐 R-P 做循环动画。Prompt Travel 是按帧号排提示词的调度：比如 0 帧猫、10 帧狗、20 帧鸟，动作在帧与帧之间渐变。闪烁用 FreeInit 的频域滤波压，顺滑度可以用 FILM 插帧翻倍。输出能同时存 GIF、MP4、WebP、PNG 帧与 TXT 元数据；图生图还能单独指定末帧图与 latent power。

## 我们怎么用

用原创角色重做时，做循环先试 Closed loop R-P；动作跨度大、想让角色中途变形的，用 Prompt Travel 按帧号排动作阶段；闪烁明显就开 FreeInit 默认值；成片先出 PNG 帧再拼 GIF，方便逐帧验收。
