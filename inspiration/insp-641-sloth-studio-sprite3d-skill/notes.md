# 笔记

## 它是怎么做的

先把角色重绘成四视角 T 形姿势图，Hunyuan3D-2 在免费 Hugging Face 空间里生成 3D 网格，再把贴图投到模型上并补齐遮挡部分，Blender 里绑 17 根骨骼并蒙皮，最后在无头 Chrome 里渲染走、跑、打三个动作各 8 个方向；每步都有通过、警告、失败检查（如脚是否着地、贴图覆盖率），失败就重做该步；输出 256px 透明 PNG 条带、96px 精灵表与预览 GIF。

## 我们怎么用

借这条 2D 转 3D 再出 8 方向精灵表的路线，作为游戏精灵表方向的备选方案；逐环节检查的思路可写进我们的工作流验收；实测成本数据作为评估该路线投入的参考。
