# 笔记

## 它是怎么做的

- 起因是直接要 GIF 只拿到单帧 PNG：改走保底路线，先要一张 3×2 六帧精灵表，再本地切片拼成 GIF，不依赖原生 GIF 输出。
- 实测了四个动画（纸船、黏土狐狸等），结论是六帧够用：帧数少反而稳，动作幅度小、背景素，循环就顺。
- 规格参考很具体：六帧、每帧 140ms、512×512、500KB 以内；背景用纯色大色块，防止逐帧闪烁。
- 顺序是先定角色静帧、再批量做动作：静帧定稿了，六格动作才不会各画各的。

## 我们怎么用

- 借保底路线：原生 GIF 输出不到账或不稳时，改走六帧精灵表加本地切片，不用干等。
- 借六帧的规格参考：140ms、512×512、500KB 以内，可以当小动作 GIF 的默认参数。
- 借纯色大色块背景的做法：背景越素，逐帧闪烁越少。
- 借先定静帧、再批量做动作的顺序：与我们先审定妆照再批量出的流程一致。
