# 笔记

## 它是怎么做的

作者不用视频模型，在 Codex 订阅额度里跑完一条 5 秒纸片拼贴 B-roll。链路分四步：先把一句抽象口播翻译成视觉隐喻卡，只确认这一步；再按案例拆出的风格参数（平涂色场、黑白半调剪片、彩色卡纸点缀、机切边加奶油白描边、柔和投影、纸纤维）出一张静帧，AI 按清单自查重出；然后以静帧为终点，用 assemble-from-empty 的方式出循环 GIF——从空场开始按固定顺序一块块拼成静帧，定格后再清场回空场接循环；最后用 ffmpeg 把 GIF 转 MP4 进剪辑。动作描述的规矩是顺序固定、每物件写清进场方式与停留点、用滑入/落下/卡位这类物理动词、镜头锁死不加新物件。拼贴风颜色少，GIF 的 256 色基本够用，不易出色带。

## 我们怎么用

借四点换原创角色重做：隐喻卡只确认一次的结构；风格先给案例再拆成可复现参数的做法；先定死静帧、GIF 只负责拼合的顺序；assemble-from-empty 的动作编排。动态海报可以直接用这套拼贴做法，物件控制在 3–6 个、主体放中间 70%、留大块纯色空场当动画起点。不要照搬它的月亮、剪刀、胶片时钟等具体画面和提示词原文。
