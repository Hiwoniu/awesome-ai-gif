# 笔记

## 它是怎么做的

指南讲两条路线：对话内直接生成 GIF，与 GIF Factory（Codex Skill）批量做贴纸；五段式 GIF 提示词结构是主体、外观、动作、固定元素、循环收尾，附可直接抄的示例提示词；GIF Factory 工作流是参考图、选风格、生成、脚本合成、导出检查；引用 OpenAI 官方帮助页的能力边界说明。

## 我们怎么用

借它的五段式结构：我们写 GIF 提示词也按主体、外观、动作、固定元素、循环收尾五段写，缺哪段补哪段；批量做贴纸时照 GIF Factory 的结构化流程走。
