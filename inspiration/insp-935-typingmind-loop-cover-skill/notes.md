# 笔记

## 它是怎么做的

Loop Cover 是 charlie947 的 motion-graphics-skills 里的一个 Skill，做法是把一张静态封面变成循环 GIF，但只让一个元素动。流程分两步：先问清三件事——封面本身、哪一个元素会动、它怎么动（脉冲、描绘、缓慢漂移或辉光，一次只选一种）；再动手做：封面是 HTML 就只给指定元素加时间函数动画并截 180 帧（20fps、9 秒）；封面是图片就按颜色取 mask，只改局部像素逐帧推进。验收标准是首帧必须能独立当封面、循环不能跳。

## 我们怎么用

借“只动一处”的决策顺序与验收标准：做动态海报或封面时，先定封面、再定唯一动效元素、再定一种动法；用我们自己的原创画面重做，不照搬它的示例封面。按颜色取 mask 只改局部像素的做法，可以作为静态海报变动图的低成本路线。
