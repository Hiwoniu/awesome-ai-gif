# 笔记

## 它是怎么做的

Skill 给出 Slack 两档规格与动画点子（抖动、脉冲、弹跳、旋转、淡入、滑入、缩放、粒子 burst），Claude 按 GIFBuilder 流程用 Pillow 一帧帧画、组装、再跑校验器核对尺寸、帧率与色数；动画模式是先标题停留约 1.2 秒，再逐个揭示节点、每次停留约 0.7 秒，最后完整画面停留约 4.5 秒；依赖只有 Pillow、imageio 与 numpy。

## 我们怎么用

借它的逐帧揭示模式做信息类动图：标题先停留、内容逐个出现、终帧长停留；Slack 两档规格写进导出参数表；Pillow 手绘帧作为无模型依赖的备选路线。
