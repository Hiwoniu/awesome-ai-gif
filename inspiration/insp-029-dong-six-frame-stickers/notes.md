# 笔记

## 它是怎么做的

六步全流程：选入口（ChatGPT 或国内第三方平台）→ 用六格提示词画 3 列×2 行的连续动作图 → 按三样验货 → 用在线工具切格、按 100-150 毫秒合成 GIF → 压到微信规格（240×240 左右、体积上限以官方为准）→ 决定是否上架。六格提示词的要点是写清格数、角色一致性、末帧接回首帧、无文字。另附即梦、剪映、豆包、Canva 的 B 计划与横向对比。

## 我们怎么用

借它的全流程清单：我们的新手流程也可以照这六步写；六格提示词的四个要点（格数、一致性、首尾接回、无文字）可作提示词检查清单；B 计划的横向对比提醒我们：视频路线转 GIF 在一致性与体积上都不如序列图路线。
