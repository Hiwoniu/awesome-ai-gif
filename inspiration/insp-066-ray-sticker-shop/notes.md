# 笔记

## 它是怎么做的

- 中文 Skill，装进 Claude Code 或 Codex 就能用：一张照片或角色图锁定整套形象，批量出 8 张动态表情。
- 输出按微信表情开放平台的规格来：240×240 GIF，自动压到每张 500KB 以内，交之前自动校验一遍。
- 不只出表情：封面、聊天图标、详情页横幅、打赏图这五件套一起生成，还附投稿文案与交付包。
- 成本记在 costs.jsonl 里：8 张表情加 5 张配套图约 0.7 美元，多试一次多花一次的钱。

## 我们怎么用

- 借它一图锁定形象、批量出整套的流程，换成我们自己的原创角色。
- 240×240、500KB 自动压缩加规格自检的做法可以直接当交付清单。
- 五件套一起交付的组织方式值得学：表情包不只是表情，还有封面与横幅这些配套。
- 只做自己有权利的角色；微信是否通过由平台决定。
