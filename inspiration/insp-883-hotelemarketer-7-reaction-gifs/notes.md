# 笔记

## 它是怎么做的

作者先把自己画成一个卡通角色（定妆照只做一次，之后每张 GIF 都挂同一张角色图），再用 3×3 九帧精灵表出 7 张反应 GIF，每张配一句场景提示词。7 张里 3 张能用、4 张翻车，文章把翻车原因逐条写出来：咖啡杯颤抖幅度太小、笔记本屏幕背对观众、手机光只是一个角落小光斑。能用的 3 张被总结成一条规律：每张都要有一个变化够大的道具（纸堆爆发、彩带、黎明），再加一个直视镜头、停留近一秒的凝视。时序上首帧停 0.5 秒、主反应停 0.9 秒，其余帧 0.2 秒；文案最后才加在画面上方横条里，避免模型九帧各写一遍导致错字。最后给了一个“交给 Agent 跑流水线”的简报写法：列出文案清单、每张先验格子再切片、失败两次就停下来问人。

## 我们怎么用

这条最值得抄的是“翻车对照表”：做反应 GIF 时先检查变化够不够大、凝视有没有直视镜头，两个缺一就别指望在小图上读得懂。时序写法可以直接套：首帧与主反应加停顿，其余帧匀速。定角色流程也值得抄：先定一张原创角色图，系列 GIF 全部挂它，不要每张重新生成角色。文案后加的做法对微信表情包尤其有用：文案横条固定不动，只有脸在动，错字风险小很多。注意作者用的是自己的照片做原型，我们换成原创角色，只借方法。
