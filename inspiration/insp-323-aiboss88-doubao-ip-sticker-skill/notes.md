# 笔记

## 它是怎么做的

教程的路线是先在豆包工作里装一个 IP 形象 Skill，用一句话定出原创 IP 头像，再基于同一形象衍生变体和打工人表情包，最后把这次制作中沉淀下来的要求写成结构化 SOP，存成自己的 sticker-pack Skill 以后复用。构图上提到用角落探头的方式保证小尺寸下依然可辨识。

## 我们怎么用

借“IP 形象先行、再批量扩表情包”的顺序，以及“把制作标准沉淀为 Skill”的做法，换成我们自己的原创角色和豆包/ChatGPT 工具链重做；角落探头这类小尺寸可辨识的构图思路也可以试。对方教程里的 IP 形象与文案不照搬。
