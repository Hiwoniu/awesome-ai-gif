# 笔记

## 它是怎么做的

Ludo AI 的一个工具页：把一张静态精灵图变成完整动作库。四种输入方式：文字动作提示词、3 张手绘关键帧、参考视频、641 个动作预设（34 类、5 机位、8 方向，带视频预览）。可以导出 GIF、精灵表 PNG、JSON 图集、MP4，帧数最高 64，带 loop 剪裁。页面 2026 年 11 月更新。

## 我们怎么用

借它的动作预设库思路：做游戏精灵或多动作表情包时，先按 walk / run / idle / attack / reaction 这类命名动作列一张动作清单，再按首帧加末帧两帧插值的方式出动作。注意它与池内 insp-077（精灵图生成器）、insp-762（VFX 精灵工具）是同一平台的不同工具页，静态图变动作是独立功能。
