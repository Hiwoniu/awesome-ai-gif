## 它是怎么做的

Stable Diffusion 生成平滑 GIF 的三步指南：找资源（帧网格 LoRA 等）→ Auto1111 脚本出 GIF → Flowframes + RIFE 插帧平滑。
“生成→成 GIF→插帧平滑”三段式旧但有效的平滑 GIF 工作流；帧网格 LoRA 这类按帧排布的生成资源选型思路。
