# 笔记

## 它是怎么做的

分两条路线：主路线是让模型画一张严格的 4×4 精灵表（16 帧、等格、固定比例和地平线），再用切片脚本把表切成帧、抠掉背景、把每帧对齐到同一条地平线，最后输出循环 GIF、干净的图集 PNG 和 TexturePacker 格式的 JSON（给 Phaser 用，另附 Godot 步骤）；另一条是原生 GIF 路线，表藏在模型内部直接出 GIF。两种路线给了对比表。

## 我们怎么用

借它的严格格表规格和切分后处理思路：我们的精灵表也可以先定死格数、比例、地平线，再写脚本统一处理，而不是靠肉眼一张张对。游戏引擎用的图集 JSON 输出方式，值得在需要接引擎时参考。角色换成我们自己的。
