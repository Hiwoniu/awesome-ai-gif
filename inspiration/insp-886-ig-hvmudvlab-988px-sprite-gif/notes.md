# 笔记

## 它是怎么做的

这条教程的核心是一个分辨率对照：直接点内置 GIF 按钮，出来的图只有 224 像素；改走精灵表路线——让模型画一张 3×2 六帧的表，末帧接回首帧，再切帧用免费 GIF 工具合成——能出到 988 像素。视频里一次展示了八种示例（黄色怪物吉祥物、跑步吐司等），并提供了一份覆盖这八种风格的提示词包，评论“GIF”可领取。做法本身与池里其他精灵表教程一致，新增的信息就是 224 与 988 这组数字。

## 我们怎么用

这组数字直接决定我们的工作流取舍：要清晰度就走精灵表路线，不要贪内置按钮的方便。八种示例的选角思路也可以参考：吉祥物、食物拟人、反应表情各取一两例，先覆盖面再深入。注意这条只凭搜索摘要收录，未打开原帖核实，988px 的具体切帧与合成参数以后补看。
