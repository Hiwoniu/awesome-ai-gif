# 笔记

## 它是怎么做的

- 视频演示 Images 2.6 直出 GIF 的完整流程：打一句话或上传一张图、调播放速度、逐帧修、把角色存成参考图保持一致。
- 核心是一条翻页书式循环提示词：先定帧数，再按顺序列出动作序列，最后要求末帧自然接回首帧，同时固定机位与背景、不写文字。
- 动作序列的编排是坐下、看到东西、歪头、摇尾、跳起、再坐下：起、承、转、合之后回到起点，循环时不跳帧。
- 选材原则是单动作、短时长：一个 GIF 只做一个小动作，时长短，循环才顺；三类值得做的 GIF 都是这个路数。
- 视频说明里写了核对来源：按 OpenAI 的 Images 2.6 发布文章核对过，示例画面是为视频重做的。

## 我们怎么用

- 借翻页书式提示词结构：定帧数、按顺序列动作、末帧接回首帧、固定机位与背景，可以直接当表情包提示词模板的骨架。
- 借动作序列的编排节奏：起、承、转、合再回到起点，复杂一点的表情也可以按这个节奏排。
- 借单动作、短时长的选材原则：一个 GIF 只做一个小动作，不要贪多。
- 只借提示词结构，不抄它的示例动作序列原文；换成我们的原创角色重做。
