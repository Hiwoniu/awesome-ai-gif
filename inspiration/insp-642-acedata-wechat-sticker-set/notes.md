# 笔记

## 它是怎么做的

先让 Agent 一次生成 9 只不同风格的水豚排成 3×3 九宫格，挑中一只泥塑质感、穿黄色雨靴的角色作为唯一参考；再用该角色先做早安、鼓掌、求抱抱、耶 4 个常见场景验证一致性，确认头身比、配色、雨靴等关键特征稳定后，再让 Agent 按感恩、拒绝、期待等日常情绪自由补齐到 10 张；最后用同一角色做头像与 750×400 的详情页横幅，一起提交微信表情开放平台审核。

## 我们怎么用

借它的工作流：我们的表情包先九宫格选角定角色，再小批量测 4 张验证一致性，稳定后再扩量；头像与横幅配套、上架规格写进我们的成套交付清单。
