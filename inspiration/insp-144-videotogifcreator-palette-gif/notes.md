# 笔记

## 它是怎么做的

视频转 GIF 的工具，核心是 ffmpeg 的两段式调色：先 palettegen 从视频里生成一张调色板，再 paletteuse 用这张板去编码，画质比直接转好很多，还能加抖动。参数有起始点、帧率、宽度，另附 JSON API 与 MCP 服务，可以接自动化。

## 我们怎么用

借两段式调色板方法：我们自己的视频转 GIF 环节可以照这个流程写——先取板再编码，不要直接转。帧率、宽度、抖动的权衡也可以写进规格：要画质就降帧率保宽度，要体积就反过来。API 化的思路适合以后把转 GIF 接进批量流程。
