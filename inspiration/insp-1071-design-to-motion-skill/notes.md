# 笔记

## 它是怎么做的

流程：Figma 帧或截图 → HTML 像素级重建 → 每个卡片演绎一个 3–8 秒循环故事，首尾回到原设计；捕获不用录屏，用 Playwright 假时钟以整毫秒步进、逐帧截图驱动 CSS 过渡，得到确定性 60fps 帧序列与干净的循环接缝；再用 ffmpeg 编码（X 用 H.264 CRF 15、网页用 palettegen GIF）。该仓库曾登 GitHub 全语言趋势榜第 1。

## 我们怎么用

动态海报的“静态稿变动图”环节照搬这套捕获法：先做一张静态海报定稿，再用假时钟逐帧驱动 CSS 过渡出循环，解决录屏帧率不稳、接缝跳帧的问题。
