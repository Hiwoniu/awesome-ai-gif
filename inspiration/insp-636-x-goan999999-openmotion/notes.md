# 笔记：X @goan999999：OpenMotion 参考视频逆向出可编辑动效结构，可导出 GIF

## 它是怎么做的

- 开源项目 OpenMotion（github.com/nexu-io/openmotion）：输入一段参考视频，AI 分析其中的镜头切分、字幕、转场和动效结构。
- 产出一个可编辑的版本：文案可改、画面可换、时间轴可调，最后导出 MP4、MOV、WebM 或 GIF。
- 原帖（2026-11-19）只介绍了项目与工作流，没有给 GIF 模板、提示词结构、帧数或尺寸规格，主帖也没有 GIF 动图演示。

## 我们怎么用

- 动态海报、动态签名这类动图，可以先找一段动效结构喜欢的参考视频逆向出骨架，再换成原创角色与文案重做，省去从零设计动效的时间。
- 只借动效结构与时间轴编排，不搬运参考视频的画面、角色与文案。
- 与 insp-627（同为 nexu-io 的 motion-anything，聊天驱动生成动效）对照：一个是逆向拆解，一个是正向生成，可互补。
