# 笔记

## 它是怎么做的

这个开源 Skill 让编码 Agent 直接写 lottie.json 与 controls.json 生成 Lottie 动画，内置 Skottie 播放器实时热重载预览；提示词原则是拿 SVG、真实数据或截图给模型打底，再用缓动术语与镜头语言控制关键帧曲线；每个动画一个 scene 目录，lottie.json 即成品。

## 我们怎么用

借它的工作流形态：动态海报也可以走“提示词出矢量动画 JSON、实时预览、再改”的路线；controls.json 插槽的参数化设计值得用到我们自己的动画模板里。
