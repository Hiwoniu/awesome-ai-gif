# 笔记

## 它是怎么做的

包级流程分三步：先做一张定妆照并让用户审过，再按 6-8 种情绪、每种一个短词各出一张循环 GIF，每张 GIF 都从同一张定妆照出发；最后用导出脚本按各平台规格转码（微信 GIF、Telegram 视频贴纸、WhatsApp 动态 WebP、LINE、Discord、Slack），规格都标注了核对过的官方文档链接。还引用了 X 上走红的一个六款贴纸模板作为佐证。

## 我们怎么用

借它的包级规划：先审定妆照、再按情绪批量出 GIF、最后统一按平台规格导出。我们的规格表可以照它的做法逐项标注官方文档来源，避免凭印象写数字。角色换成我们自己的，不用它的示例吉祥物。
