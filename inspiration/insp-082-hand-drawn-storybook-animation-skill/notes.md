# 笔记

## 它是怎么做的

- 工作流分两段：先是剧本段，剧本经三轮打磨、再拆分镜与运镜；然后是绘制段，代码在浏览器里实时画出画面，而不是逐帧生图。
- 代码绘图的好处是风格统一、可局部修改：线稿晕染、翻页转场都由代码算出来，改一处不用整页重画；同一套流程换参数就能切水彩、水墨、工笔长卷等风格。
- 声音与画面对齐是反向调的：先定豆包语音的时长，再按语音时长反向调整画面节奏，而不是先画好画面再配音。
- 交付是完整成片：生成式配乐加中英双语字幕，附多部成片演示，证明同一流程能出不同风格。

## 我们怎么用

- 借剧本三轮打磨、再拆分镜与运镜的工作流：我们的动态绘本也可以先把剧本打磨到位，再动手画。
- 借代码实时绘制的思路：绘本里线稿晕染、翻页转场这类效果，用代码算比逐帧生图更稳、也更容易局部改。
- 借按语音时长反向调画面节奏的做法：有配音的绘本先定语音时长，再排画面节奏。
- 借同一流程切换多风格的复用结构：水彩、水墨、工笔长卷共用一套流程，换风格只换参数。
- 只借工作流，不抄它的剧本与成片；原 Skill 的许可证以 GitHub 原仓库为准。
