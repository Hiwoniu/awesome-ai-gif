# 宠物档案 profile.json

多张照片建档时写这份，放在工作目录里。照片本身不入库，档案可以入库（不含定位、主人信息）。

```json
{
  "name": "多多",
  "photos": 7,
  "looks": {
    "breed_guess": "银渐层（英短），短毛，体型圆润",
    "coat": "哪里是什么颜色，按部位写：脸、下巴、胸口、肚皮、脚、背、体侧、尾巴、额头花纹",
    "eyes": "颜色、形状、眼线",
    "nose": "颜色和周围",
    "ears": "大小、形状、内侧颜色",
    "face": "脸型和天然表情（比如嘴角天然往下，看着像委屈）",
    "signature": ["2–3 个特征件，验货就查它们"]
  },
  "habits": [
    {"photo": "p01", "action": "照片里在做什么", "meaning_hint": "能做成什么表情 / 字"}
  ],
  "traits_from_photos": [
    {"trait": "照片能看出的倾向", "evidence": ["p02", "p03"], "note": "为什么这么说"}
  ],
  "owner_answers": {
    "name": "叫什么，有没有外号",
    "signature_story": "最典型的一件事",
    "extra": "主人顺口补充的",
    "like_who": "像哪种人"
  },
  "traits": [
    {"trait": "最终性格标签", "from": ["主人", "p01"], "show_as": "画面上怎么表现"}
  ]
}
```

- `traits_from_photos` 只写看得见的（眼神、姿态、在吃东西），不要从一两张照片断定性格。
- `traits` 以主人的回答为主，照片做佐证；每个标签都要写 `show_as`，方向和表情清单直接从这里来。
- 一个方向通常抓 2 个最强的标签做主线（比如“好吃鬼 + 偷感”），其余标签分散到各张里。
