# 提示词

方括号里换成自己的内容，其余不动。

## 光栅变画卡

```
参考这张角色定稿图，画一张左右双联图，用来做“光栅变画卡”（同一画面在两个状态间切换）。
整张图 1024×1536 竖版；左右各一格，每格 512×768，两格之间没有间隔，画面铺满整格，不要在下方或四周留空白条。
角色：[一只圆滚滚的橘猫，短腿，白色肚皮，尾巴尖是白色，右耳有一个小缺口]，画成[精致的绘本插画风格，柔和的水彩上色、细腻的毛发笔触]，特征件不变。
两格的构图、机位、角色位置、大小、朝向、头部角度、眼睛和下巴的位置必须完全一致，可以逐像素对齐，只有状态不同：
左格（[日常]）：[角色坐在书桌上，戴圆框眼镜，捧着一杯热牛奶，表情困倦；夜晚的书房，暖黄台灯光]。
右格（[变身]）：[同样的坐姿和位置，眼镜变成超级英雄面罩，身后飘起红色披风，表情自信；同一间书房，灯光变成蓝紫色能量光，有光粒子]。
角色从耳朵尖到脚都在格子里，上下各留一点余量。画面里不出现任何文字、字母、数字和标点。无边框。
```

- 写死像素尺寸。只写“2:3 竖版”时，实测模型把每格画成约 512×1190，下方再留 22% 的空白。
- 两态的差别要落在**看得见的东西**上：道具换掉、表情变、光色变。只换表情的话缩小后几乎看不出翻转。
- 想要底部标题栏，让脚本用 `--footer` 画，不要让模型留空白。

## 动态海报

```
参考这张角色定稿图，画左右两幅完整的 3:4 竖版海报，合成一张没有间隔的 1536×1024 双联图（每幅 768×1024），用来做两种状态来回切换的动态海报。
人物、背景、网点和定制文字一起设计，统一的设计语言：[日式漫画印刷风格，限定三色（橘红、黑、米白），粗墨线，平涂阴影，半调网点，斜切的负空间]。
角色：[一只圆滚滚的橘猫，短腿，白色肚皮，尾巴尖是白色，右耳有一个小缺口]，保持定稿图的特征件，画成海报里的主角。
两幅锁住同一身份、同样的眼线高度、脸部大小和镜头，只有状态不同：
左幅（[安静]）：[角色抱着爪子站着，眼睛半闭，表情冷静]；上方大字收紧，是细细的描边空心字。
右幅（[登场]）：[角色一只爪子高举指向天空、张嘴大喊，毛炸开，有速度线]；上方大字撑开变成粗实心字，字形向外倾斜。
上方的准确文字只写：[橘团]。下方的准确文字只写：[今晚登场]。两幅文字内容相同，只是字形状态不同；标题和角色的耳朵、手臂有前后遮挡，但字仍能读出。
不要额外文字、不要英文、不要标志和水印，不要无关角色。
```

- 文字写成“准确文字只写：xx”，并说明两幅内容相同，模型才不会自己加字。
- 实测这条一次就对齐、字也没错（2026-11-18，GPT Image 2.6，165 秒）。
