# 角色定稿图

整套表情的第一步。先出一张满意的角色定稿图，之后所有出图都带上它当参考图。

## 公式

```
画一个原创卡通角色的定稿图，用作整套表情包的角色参考。
角色：[一只圆滚滚的橘猫，短腿，尾巴尖是白色，左耳有一个小缺口]
姿势：正面站立，四肢自然离开身体，表情平静，全身入画并居中。
风格：[简笔画卡通，线条粗细一致，颜色扁平，不超过 5 种主色]
背景：纯白，不要渐变和纹理。画面里不出现任何文字、字母、数字和标点。白色的部位和道具（肚皮、尾巴尖、气团）都要有完整闭合的深色描边。无边框、无阴影、无道具。
```

## 要点

- **写出 2–3 个特征件**（缺口的耳朵、白尾巴尖、花纹）。之后验货就是对着它们查，没有特征件就没法判断“还是不是同一个角色”。
- **四肢离身、全身入画**：后面要做各种姿势，缠在一起的定稿图会让模型把肢体画粘连。
- **主色越少越好**：缩到 240×240 还能看清，GIF 压体积也更容易。
- **只用原创角色**：不要现有 IP、明星脸、真人肖像。
- 定稿后把“角色”和“风格”两段文字原样保存到 `pack.md`，整套出图都复制这两段，中途一个字都不改。
