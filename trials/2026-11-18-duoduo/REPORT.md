# 多多·偷感干饭精（12 张）

日期：2026-11-18。主角：用户自家的银渐层英短“多多”。用户上传 7 张原图（HEIC），转成 `_work/photos/p01–p07.jpg`，**不入库**。这是第一次走“多张照片 → 认识它 → 定方向 → 出一套”的流程，全部素材来自用户自己的猫，这套可以提交微信。

## 流程

1. **转照片**：`sips -s format jpeg -Z 1600` 转 HEIC；sips 不会把方向写进像素，再用 Pillow `ImageOps.exif_transpose` 摆正，存图时去掉 EXIF（定位信息也一起去掉）。
2. **看照片建档**：7 张拼成 `photos-sheet.jpg` 一起看，记下长相（银白脸、灰绿大圆眼带黑眼线、粉鼻子、嘴角天生往下）和每张照片里的动作、神态，写进 `_work/profile.json`。
3. **问主人 3 个问题**：叫什么、有什么招牌故事、像谁。主人答：好吃鬼，一撕零食袋就喵喵跑来；像小狗猫，喊了就来；有点笨；贼眉偷感很强；有点贱贱的。
4. **归纳性格**：好吃鬼、偷感强、小狗猫、有点笨、贱贱的、眼神戏多。
5. **给方向**：给了 3 个方向，各配一种画风，用户选 A「偷感干饭精」，用真实照片风格。
6. **定 12 张**：围着“听见撕袋子 → 跑来 → 要 → 偷 → 装无辜 → 吃饱”排一条故事线，再补几张聊天常用的（盯、嘿嘿、啊？）。

## 出图（Codex CLI，13 次）

- 一次出完：`codex_gen.py each _work/gen --image ref-face.jpg --image ref-body.jpg`。参考图 1、2 用来锁长相，取自 p03 正脸和 p05 全身。
- 有 6 张的动作本来就在原照片里（03、04、07、08、09、12），把那张照片放进子目录当 `ref.png`，借它的姿势。
- 每张约 60–74 秒。
- 第一轮 12 张里，11 张一次就能用。
- 11「啊？」第一版和 09「我很乖」几乎一样，都是端坐看镜头。提示词改成“头往一侧歪约 45°”，并写明“要和端正坐着看镜头的照片明显不同”，重出后可用。旧图留作 `new-v1.png`。

## 合成
