你问的版本号没记错：GPT Image 2.6 真实存在，就是当前最新版，2026-11-04 发布，原生能出 GIF 动图。更重要的是，11 月初刚集中冒出一批专做微信表情包的开源 Skill——从出图、切图、压体积到上架机检，一条龙都有现成的。下面是每个数字的出处和可信度标注。

可直接抄的提示词公式（官方 + 实测教程综合）

骨架来自 OpenAI 官方博客给出的 sprite-sheet 公式（示例主角是 Q 版社畜：看股票大跌落泪 / 大涨撒钱），细节按懂 AI 教程与 Oimi 工作流的实测要点补齐。把黄色部分换成你的角色和动作即可。

生成一张用于无缝循环 GIF 的单张动画序列图，用来做微信表情包。严格包含 6 个连续帧，按 3 列×2 行网格排列，从左到右、从上到下阅读，每个面板尺寸完全一致。
角色：[一只圆滚滚的橘猫，线条简单，颜色扁平]
动作：[从趴着到慢慢抬起头，再眨一下眼，最后回到趴着的姿势]
固定前侧四分之三机位，六个格子里是同一个角色、同一套配色、同一个姿势起点。第 6 帧要平滑过渡回第 1 帧。
风格：简笔画卡通，颜色扁平，适合缩小到 240×240 时仍然清晰。
背景：纯白。无字幕、无文字、无边框、无留白、无阴影。

为什么每一句都不能省

  • 不写“3 列×2 行 / 6 帧”→ 会出 4 格或 9 格
  • 不写“面板尺寸一致”→ 切片错位
  • 不写“同一角色 / 同一配色”→ 变脸
  • 不写“第 6 帧回接第 1 帧”→ 循环会跳
  • “无文字”必须写——模型爱自己加字，而且经常加错字
  • 纯白底比透明底稳：直出透明不稳定，白底后期好抠

风格一致性六条（多源一致）

  • 先出 1 张角色定稿（正面站姿、四肢离身、纯色背景），满意再批量延展
  • 同一套只用同一张参考图 + 同一段风格描述，中途不改描述
  • “先合后分”（多宫格/序列帧）比逐张生成更稳
  • 验货盯特征件：耳朵、尾巴、衣服花纹最容易丢
  • 坏格只局部重绘那一格，不动其余格
  • 240×240 下细微表情看不清：动作幅度要大、轮廓要清
06

最小流程：从一句话到一套能上微信的表情包

两条路线选一条。零代码版适合先跑通第一套验证手感；Agent 版适合批量和长期做号。

1

先定三件事

角色越具体越好（有参考图最佳）；一次只做一个动作；风格锁定简笔画卡通——新手首选，缩到 240×240 仍然清晰。别碰 3D 毛绒风做第一套。

2

ChatGPT 里粘贴六帧提示词

用上方公式生成 3 列×2 行序列图（Images 2.6，ChatGPT 内直接可用）。

3

验货三点

六格等大；耳朵/尾巴/花纹等特征件没丢；首尾帧能接上。坏格用 markup 圈选局部重绘，只改那一格。

4

ezgif 切图合成（免费免注册）

ezgif.com 的 Sprite sheet cutter 按 3×2 切开 → GIF Maker 按序上传、每帧 100–150ms、勾无限循环 → Resize 到 240×240 → 再 Optimize（减帧/降色）压到 ≤500KB。顺序别反：先缩尺寸再压体积，反过来会二次损失画质。

5

凑满一套 + 配套素材

重复做到 8 张（最少成套数），每张含义词 ≤4 字、不重复；再做封面 1 张（240×240 PNG 透明底）、图标 1 张（50×50 PNG 透明底）、横幅 1 张（750×400、不透明、非纯白、无文字）。

6

先自用，再上架

先在家人群/朋友群当贴纸发 1–2 天，确认“别人看得懂情绪”，再去 sticker.weixin.qq.com 注册提交审核。

1

装 Skill

ray-sticker-shop 装到 Claude Code / Codex 的 skills 目录：

git clone https://github.com/imraywang/ray-sticker-shop ~/.claude/skills/ray-sticker-shop pip install pillow
2

配 Key（可选）

设 OPENAI_API_KEY 直连官方，或配 OPENAI_BASE_URL 走中转。不配 Key 也行：Skill 给提示词，你去 ChatGPT 出图后回填合成。

3

一句话开工

对 Claude Code / Codex 说：“把这张猫的照片做成一套表情包。”Skill 会走完：参考图锁角色 → 出图 → 切 240×240 → GIF 压 ≤500KB → 封面/图标/横幅/赞赏图 → 规范自检 → 上架文案与交付包。

4

上架前再过一道机检

用 charmoji 的检查脚本对成品目录跑一遍（尺寸/体积/透明/差异哈希/文案字数）：

git clone https://github.com/webkubor/charmoji-sticker-skill.git python3 scripts/check_assets.py <系列目录>
5

提交

到微信表情开放平台按表单上传。记住：超规格素材平台不报错、直接静默压缩裁剪，所以第 4 步不能省；审核没过要在原专辑上编辑重提，不要新建一套（官方明文不允许提交重复表情）。

07

微信上架规格：照着这张表做，别猜

入口：微信表情开放平台 sticker.weixin.qq.com（电脑端）。注册仅面向中国大陆身份：个人需大陆居民身份证 + 已绑银行卡的微信。下表为官方规范归档（抓取 2026-08-26，官方声明为动态文档，投稿前请复核当页）。

素材数量格式尺寸大小背景 / 要点
表情图专辑 8–24 张；单品 1 张动态 GIF；静态 PNG/JPG/GIF240×240≤500KB同专辑统一动态或静态；动态须循环流畅；风格统一、各张差异足够；表情图本身无强制透明（照片型合法）
表情封面图1PNG240×240≤500KB须透明底；正面半身/全身为佳，忌只用头部、忌白描边/锯齿/方框
聊天面板图标1PNG50×50≤100KB须透明底；头部正面为佳
详情页横幅1PNG/JPG750×400≤500KB禁透明底、禁纯白底；图中避免任何文字；色调活泼、与微信底色区分大
表情缩略图与主图数量一致PNG120×120≤50KB透明底。差异点 xiaopengs 文档称必填，charmoji 归档的官方概览表未列此项——投稿前以平台表单为准
艺术家主页横幅1JPEG/PNG750×400≤80KB与详情页横幅不是同一张；避免白色/近白背景与边缘
赞赏引导图 / 致谢图各 1GIF/PNG750×560 / 750×750≤500KB避免透明底；引导语 5–15 汉字；用 emoji 二次创作的作品不可开赞赏
艺术家头像1JPEG/PNG640×640≤500KB建议真人头像

文案规则：表情名称 ≤8 汉字（≤5 最佳）、无标点空格、别与已有专辑重名；介绍 ≤80 字；版权 ≤10 字；含义词 ≤4 汉字、同套不重复、用普通话，且与张数一一对应。

审核周期别信单一说法：市面上有 1–3 / 3–5 / 5 / 10 个工作日四种口径并存，以平台当前页面为准。变现：付费表情需至少 1 套已上架 + 近 3 个月无违规，每套 10 微信豆，技术服务费 10%，免费↔付费不可互转。

来源：charmoji 归档的官方规范全文 · 微信官方制作规范页

提交前自查清单（照着逐项过）

  • 深色底查白边把每张图放到纯黑底上看一遍，羽化白边肉眼在白底上看不见，审核能看见
  • GIF 做 1-bit 透明半透明像素二值化（阈值 128 + 主体腐蚀 1px），别用“杂边设为白色”糊弄
  • 整套差异够不够只换文字/微调凑数是第一大拒因；动作要真不一样
  • 无 IP、无明星脸知名 IP、影视截图、公众人物肖像、未授权同人必拒
  • 画面干净无水印、二维码、第三方 logo、微信号引流；画面里别写“微信”二字（真实驳回案例：被判推广）
  • 横幅合规750×400、无文字、非纯白、非透明
  • 封面/图标透明底封面别只用头部特写，别加白描边和方框
  • 文案逐字数名称 ≤8 字、含义词 ≤4 字不重复、介绍 ≤80 字，无商标蹭名

八大被拒原因（多源一致 + charmoji 实测记录）

✕

1. 白边 / 半透明边缘（最高频）

封面和图标尤甚。解法见自查清单前两条。

✕

2. 整套差异不足

仅换文字、微调凑数、动作高度相似。charmoji 称此为“第一大拒因”，用差分哈希拦截。

✕

3. 侵权 / 撞脸

迪士尼/宝可梦等知名 IP、明星脸、影视截图、公众人物肖像；未授权二创必拒。

✕

4. 画面不干净

水印、二维码、第三方 logo、外部链接引流；画面写“微信”二字会被判推广非自有版权应用。

✕

5. 横幅 / 封面违规

横幅含文字、纯白底、透明底；封面头部特写、白描边、方框。

✕

6. 文案违规

含义词超 4 字、重复、与张数对不上；名称蹭商标/热点品牌；介绍含推广信息。

✕

7. 规格错误

尺寸/体积超限被平台静默裁剪导致主体被裁；动态静态混在一套；单品含人物肖像。

✕

8. 变现相关

emoji 素材二次创作不可开赞赏；付费表情不可重复投稿到其他平台。

两条推荐路线：免费先跑通，付费再量产

免费路线

¥0 起 · 只花时间
  • 出图：ChatGPT Images 2.6 + 六帧公式（官方称所有档位可用，但免费档额度未核实，见未核实清单第 1 条）；或即梦 AI / 豆包（中文提示词友好）作 B 计划

  • 抠图：rembg 本地免费（商用换 birefnet-general 模型）或 ezgif 的 Replace color（容差约 10%）
  • 机检：charmoji 的 check_assets.py，不出图也能单独用
  • 上架：微信表情开放平台，无平台费用
  • 短板：免费档额度/速度未核实；逐张验货和手工切图耗时；一致性全靠提示词 + 参考图

付费路线（推荐）

单套约 ¥5–15 量级*
  • 出图：API 用 gpt-image-2.6-sunburst（medium/high 求一致性）或 flare（low 求快）；单张参考价 low $0.025 / medium $0.043 / high $0.053
  • 自动化：ray-sticker-shop 一条龙；或 animated-sticker-studio 做多平台分发
  • 抠图/机检：charmoji 规格机检 + rembg（BiRefNet）
  • 上架：同免费路线
  • *预算提醒：按实测 token 估算的量级，不是报价。别用旧资料的“整套 $0.70”做 2.6 预算——2.6 的 token 消耗是 2.5 的 3–4 倍，先小批量实测再定量
